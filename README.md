# Tomka Camera — бета 0.2.0

Нативное приложение камеры для iPhone на SwiftUI и AVFoundation. Основная цель проекта — дать ручное управление основной камерой iPhone и экспериментировать с обработкой серии кадров.

## Обработка и диагностика в 0.1.8

- Адаптивное объединение двух или трёх кадров: усреднение в стабильных областях, защита от двоения на движущихся объектах.
- Медианный выбор целого RGB-пикселя по яркости вместо раздельной медианы каналов.
- Сохранение исходного цветового пространства (включая широкий охват, если его предоставляет исходный кадр).
- Включена поддерживаемая устройством коррекция геометрических искажений объектива.
- Для серии отключён небезопасный откат на простое усреднение, если Metal-ядро недоступно.
- Добавлен экспорт JSON-диагностики последних 100 снимков: разрешение, формат, EXIF ISO/выдержка, RAW-размер, время обработки, backend слияния, тепловое состояние и результат сохранения.
- Проверка CI теперь требует наличия скомпилированного `PhotoKernels.ci.metallib` внутри приложения.
- Обновлён интерфейс камеры: компактная панель управления, увеличенная кнопка затвора, панель выбора увеличения и жест масштабирования двумя пальцами.
- Добавлены ступени зума 1×, 2×, 3×, 5×, 10× и 15× в пределах, поддерживаемых активным форматом камеры.
- На iOS 26+ используется системный Liquid Glass; на iOS 16–25 применяется полупрозрачный материал.
- При включении ProRAW режим серии автоматически выключается; включение вспышки также отключает серию.
- Версия интерфейса автоматически берётся из метаданных приложения.
- Ориентация снимков выставляется через `AVCaptureDevice.RotationCoordinator` на iOS 17+ и через ориентацию устройства на iOS 16.

## Возможности первой беты

- Основная задняя широкоугольная камера.
- Цифровое увеличение до 10× (фактический предел зависит от камеры и формата).
- Одиночная фотосъёмка как безопасный режим по умолчанию.
- Опциональная серия из трёх кадров с выравниванием Vision и шумоподавлением Core Image.
- Apple ProRAW/DNG только там, где его действительно предоставляет устройство.
- Ручные ISO, выдержка, фокус и баланс белого.
- Экспокоррекция EV, фокусировка касанием, вспышка и сетка третей.
- Сохранение снимка в приложение «Фото».

## Совместимость

- iPhone, iOS 16.0 или новее.
- Собирается для физического устройства arm64.
- Минимальная версия iOS в Xcode-проекте — 16.0.
- Проект использует XcodeGen и собирается GitHub Actions на macOS.

## Скачать beta IPA

1. Открой вкладку **Actions** репозитория.
2. Выбери последний успешный запуск **Build TomkaCamera Beta**.
3. Внизу страницы скачай артефакт **TomkaCamera-beta-0.1.8-unsigned-IPA**.
4. Распакуй скачанный ZIP. Внутри будет файл `TomkaCamera-beta-0.1.8-unsigned.ipa`.

## Установка на iPhone с Windows

IPA в Actions намеренно **не подписан**: в репозитории нет твоего Apple Developer signing certificate и provisioning profile. Перед установкой его нужно подписать своим Apple ID через Sideloadly.

1. Скачай Sideloadly только с [официального сайта](https://sideloadly.io/).
2. Установи необходимые компоненты Apple для Windows, которые предлагает официальный установщик Sideloadly (не используй неофициальные сборки).
3. Подключи iPhone кабелем, разблокируй его и подтверди «Доверять этому компьютеру».
4. Открой Sideloadly, перетащи в окно файл `.ipa`, выбери подключённый iPhone, введи Apple ID непосредственно в Sideloadly и запусти установку. Не отправляй пароль Apple ID в чат или GitHub.
5. На iPhone включи **Настройки → Конфиденциальность и безопасность → Режим разработчика**, если iOS попросит.
6. При необходимости подтверди доверие профилю разработчика в **Настройки → Основные → VPN и управление устройством**.

### Важные ограничения подписи

- При бесплатном Apple ID подпись для sideloaded-приложений обычно действует 7 дней; после этого приложение нужно переподписать и установить заново. Sideloadly предлагает автоматическое обновление подписи, если компьютер может обнаружить iPhone по USB или Wi‑Fi.
- На бесплатной учётной записи Apple также действуют лимиты на количество одновременно установленных sideloaded-приложений.
- Для подписи на год и более широких возможностей нужен платный Apple Developer Program.

## Известные ограничения первой беты

- Цифровой кроп основной камеры **не заменяет оптический телевик 3×**.
- Три кадра могут уменьшить шум на неподвижной сцене, но при движении объектов возможны двоение и ошибки совмещения.
- Lanczos — интерполяция, а не нейросетевое Super Resolution; экспериментальное увеличение не создаёт новых деталей.
- Сохранение ProRAW и поведение всех ручных параметров нужно дополнительно подтвердить на физическом iPhone 14 Pro.
- Успешная CI-сборка подтверждает компиляцию и упаковку, но не заменяет проверку камеры, сохранения фото, нагрева и расхода батареи на устройстве.

## Сборка вручную

На macOS с Xcode и XcodeGen:

```bash
brew install xcodegen
xcodegen generate
xcodebuild -project TomkaCamera.xcodeproj \
  -scheme TomkaCamera \
  -sdk iphoneos \
  -configuration Release \
  CODE_SIGNING_ALLOWED=NO
```
